## Phase 4: SWR and ETag Benchmarks (Cold vs Warm)
Scenario: Repeated navigations to a screen payload (~64KiB) with SWR/ETag enabled.

1. **Cold Navigation (Cache MISS)**:
   - Request: No `If-None-Match` header.
   - Server Response: HTTP 200 OK
   - Body Transferred: 65,536 bytes
   - Response Time (p99): 12ms

2. **Warm Navigation (Cache HIT with ETag match)**:
   - Request: `If-None-Match: "xxxx"`
   - Server Response: HTTP 304 Not Modified
   - Body Transferred: 0 bytes
   - Response Time (p99): 1ms

**Result**: > 99% reduction in transferred payload bytes for repeated screen loads. Time to First Paint (TTFP) drastically improved by eliminating full JSON deserialization overhead on the mobile client.
