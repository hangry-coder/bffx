## Interpretation
- MemoryStore: High-performance in-memory storage for testing (~900ns per create)
- SQLiteStore: Production-ready SQLite storage (~8400ns per create, includes disk I/O)
- Both implementations follow the same interface contract with context support

## Key Metrics
- **Latency**: SQLite create operations average ~8.4μs
- **Allocations**: 33 allocations per SQLite operation vs 10 for memory
- **Throughput**: Memory store achieves ~1.1M ops/sec vs SQLite ~140K ops/sec
